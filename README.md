# AEDT Light Premium Website — v4.0

Production-ready static website for tetheraedt.io.

## Visual direction
- White + light mint/sea-green premium theme
- Uses the supplied official AEDT wordmark and diamond logo
- Responsive desktop/mobile layout
- Animated hero, market cards and clean UI components

## Included
- Home, Market, Token, Transparency, Ecosystem, Individuals, Business, Exchanges, Security, Whitepaper, FAQ, Contact and 404
- Live AEDT DEX data with fallback
- TRON latest block data
- 72-hour market chart
- MetaOneClick ecosystem and enquiry integration
- Official project channels
- SEO, OpenGraph social card, PWA manifest, service worker, sitemap and robots.txt
- GitHub Pages CNAME and .nojekyll

## Deploy
Upload the contents of this folder to the repository root used by tetheraedt.io. The included `CNAME` is already set for tetheraedt.io.

## Main editable configuration
`assets/config.js`
